## Recovery validation

The recovered code passes 116 targeted tests covering INS, Earth mechanics,
preintegration, SO(3), and independent covariance Jacobian audits. This is
implementation validation, not statistical estimator acceptance.

Fresh 300-second, 16-realization baseline runs reproduce:

| Fixture | Heading RMSE / reported sigma | Attitude/bias ANEES |
| --- | --- | --- |
| Calibrated Earth gyrocompass | 0.00858° / 0.01167° | 9.34 |
| Weak gyro-bias prior, Earth rotation | 4.50° / 0.98° | 1960 |
| Noisy gyro, zero Earth rotation | 24.98° / 1.64° | 294 |

Truth and filter use the same white-noise density and constant-bias prior.
The noisy fixture is a diagnostic of confidence, not a promise to extract
useful gyrocompassing accuracy from a noisy sensor. Zero Earth rotation
removes physical heading information yet the baseline acquires confidence.

## Recovery checkpoint experiments — historical

**Current status:** see [continued implementation and qualification](ins-nonlinear-2026-09-09.md).
A production-code opt-in now exists, but it remains experimental because larger
weak-bias trials still fail. The paragraphs below describe the earlier recovery
checkpoint.

`experiments/` contains isolated hypothesis tests. They wrap the recovered
INS for qualification and do not change its production implementation.
Commands run from the repository with `PYTHONPATH=.`. The geometric runner
selects a chart with `INS_CHART=aligned`, `gravity_bias`, or `semidirect`;
the augmented-UKF runner additionally supports the ordinary product chart.
Specify `--output PATH`; all Monte Carlo runs default to 16 realizations.

Finite charts use their own independently differentiated reset. Round trips,
zero-error differentials, body-velocity residuals, and finite yaw symmetry
have been checked independently for the swing/twist chart. A chart's bias
error is not an ambient physical bias difference: current harnesses report
physical bias RMSE and physical Euler heading separately from chart NEES.

The two-frame exact reset fixes the weak-bias fixture but fails the noisy
fixture. Separating swing and twist preserves heading uncertainty in noisy
trials; its ordinary linear predictor still underestimates accelerometer-bias
uncertainty. An augmented unscented predictor substantially reduces that
error, including during prescribed rotation. Residual vertical accelerometer-
bias offsets and pooled consistency remain under investigation. Passing one
seed batch does not establish acceptance. `data/recovery-2026-09-09.json`
records completed experiments, including failures; some earlier records use
the attitude-chart z component rather than physical Euler heading.

Do not merge the experimental covariance models based on this checkpoint.
Required next evidence includes resolving the remaining bias offset,
independent seeds, matched raw/packet cadence with boundary correlations,
mount and motion cases, complete runtime/reset integration, and regression
validation. The main branch still uses its existing product error model.
